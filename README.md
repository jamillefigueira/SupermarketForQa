# 🛒 Supermarket for QA

A fictional online supermarket web application developed to practice **Quality Assurance (QA)** and **software testing**.

The project simulates a simple e-commerce experience where users can browse products, search the catalog, view product details, manage a shopping cart, and proceed to checkout.

## 🚀 Features

- **Product Catalog:** Displays a selection of supermarket products.
- **Product Search:** Filter products by name.
- **Product Details:** Open a modal with product information, image, description, and price.
- **Shopping Cart:** Add products, update quantities, and remove items.
- **Cart Counter:** Displays the total number of items in the cart.
- **Automatic Total Calculation:** Updates the cart total whenever items change.
- **Checkout:** Simulates the checkout process.
- **Responsive Design:** Layout adapted for different screen sizes.

## 🧪 QA Practice

This project can be used to practice manual testing, including:

- Functional testing
- UI testing
- Positive and negative test scenarios
- Boundary value testing
- Cart calculations and quantity validation
- Search functionality
- Modal behavior
- Basic usability testing
- Bug reporting and test documentation

## 🎯 Project Goal

The main goal of this project is to build a practical environment for learning and demonstrating software testing skills, identifying potential bugs, and improving QA knowledge through hands-on exercises.
